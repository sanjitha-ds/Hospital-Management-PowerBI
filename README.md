# Hospital Management Dashboard – Power BI

## Overview

An interactive Power BI dashboard developed to analyze hospital
operations, patient demographics, admissions, financial performance,
and key healthcare KPIs.

## Objectives

- Analyze patient demographics
- Monitor hospital admissions
- Identify operational trends
- Analyze revenue and financial performance
- Track key healthcare KPIs
- Support data-driven decision making

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## Dashboard Features

- Patient demographics
- Admission trends
- Department-wise analysis
- Revenue analysis
- KPI cards
- Interactive filters and slicers
- Trend analysis

- Data cleaning
- Data transformation
- Data modeling

- Healthcare analytics
- Dashboard development
